# 2.6 — Registro leve de chamadas, sem gravação

Item de Fase 2 (esforço P/M, "novo na v4", sem áudio). Depende de 1.2
(timeline).

## O que foi entregue

- `supabase/migrations/0071_call_logs.sql`: tabela `call_logs`
  (contato, negócio opcional, duração em minutos, resultado, próximo
  passo). Tabela dedicada, não reaproveita `interactions` — a porta de
  saída pede medir "parcela dos registros com resultado + próxima ação",
  o que exige colunas estruturadas, não texto livre.
- `lib/timeline.ts`: novo tipo de entrada `call`, testado em
  `lib/timeline.test.ts` (título com/sem resultado registrado, detalhe com
  duração e próximo passo).
- `app/(app)/actions.ts`: `createCallLog()`.
- `app/(app)/contacts/[id]/page.tsx`: formulário "Registrar ligação"
  (duração, resultado, próximo passo) e nova aba "Ligações" na linha do
  tempo.

## Decisões de escopo

- **Sem telefonia integrada, sem áudio** — exatamente o que o item pede.
  Se o hábito de registrar pegar (porta de saída), abre-se um item
  específico de telefonia/gravação depois — não construído aqui.
- Ícone de "visita" na timeline mudou de `IconPhone` para `IconCalendar`
  (contacts/[id]/page.tsx) para `IconPhone` ficar livre para "ligação",
  evitando dois tipos de entrada com o mesmo ícone.

## Verificação

- `npm run test` (154 testes), `npx tsc --noEmit`, `npm run lint` e
  `npm run build` sem erros.
- `test/integration/rls.test.ts`, bloco `describe("call_logs (2.6)", ...)`:
  isolamento cross-org e rejeição de `contact_id` de outra organização
  (FK composta).
- **Mesma limitação de sempre**: sem Docker/Supabase local para rodar a
  suíte de integração de verdade nem abrir a página num navegador
  autenticado.
